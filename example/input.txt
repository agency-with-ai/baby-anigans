Feed shortlist project

Goal
Help a course instructor find sources relevant to upcoming lectures.
The instructor makes the final decision about using a source.

Inputs
The sweep receives unread feed entries and the current course outline.
An entry has an ID, title, publication date, source URL, and read status.
For a link-only entry, fetch the source page before judging relevance.

Selection
Screen unread entries, including older entries that have not been read.
Skip entries already marked read, even if they were published recently.
Apply the same criteria to supportive and contrary findings.
Keep relevant and borderline sources; label borderline sources explicitly.
Do not treat a model's confidence rating as evidence of correctness.

Output
Write a dated shortlist with source links and reasons for selection.
For each kept source, name the lecture it might inform.
Preserve the source's qualification when summarizing its findings.

Failure behavior
If the feed is unavailable, report the failure and write no shortlist.
A failed run must not mark any entries read.

Read status
After a successful sweep, mark screened entries read.
Exception: leave borderline entries unread until the instructor reviews them.
A source omitted as clearly unrelated still counts as screened.

Limits
The sweep drafts recommendations; it does not edit the course outline.
It must not send email, publish results, or delete source records.

Open questions
The deployment machine and authentication method have not been chosen.
